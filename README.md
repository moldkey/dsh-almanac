<p align="center"><strong>dsh-almanac — 黄历与干支</strong></p>

干支纪年、生肖、二十四节气、日期信息。本地计算，文化参考。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-almanac

## 工具

- `almanac_ganzhi`：干支 + 生肖
- `almanac_solar_terms`：24 节气（近似）
- `almanac_date_info`：日期信息

## 说明

节气为通用近似公式，可能与官方历书差 1 天；本插件仅作文化参考，不构成预测或建议。

更多工具：https://deepseekbase.com/zh/plugins/new/
